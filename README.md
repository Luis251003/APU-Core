# Apu Core

## 📌 Descripción
Apu Core es una landing page moderna diseñada para presentar los servicios y la propuesta de valor de una consultora de programación y desarrollo de software. El sitio ofrece información clara sobre la empresa, sus servicios y canales de contacto mediante una interfaz limpia y responsiva.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo
- Presentar servicios de desarrollo de software
- Comunicar la propuesta de valor de la consultora
- Generar leads mediante una interfaz clara e intuitiva

## ⚙️ Funcionalidades
- Diseño responsivo (adaptable a móviles y escritorio)
- Secciones estructuradas de servicios
- Interfaz moderna y limpia
- Sección de contacto para clientes potenciales

## 🧠 Aprendizajes
- Estructuración de landing pages con enfoque comercial
- Principios de diseño responsivo
- Fundamentos de UI/UX aplicados a servicios digitales
- Buenas prácticas de desarrollo frontend con JavaScript puro
